# primitives

## What This Is

We keep a working index for product and engineering, and primitives is the entry that collects our notes, examples and fixes. It reflects how Swift Tech Co. actually uses this in builds and client work.

## Images

[![primitives](images/preview.png)](https://github.com/Swift-Tech-Co/primitives)

## Installation

First, install pnpm if you haven't already. Open your terminal and run:

```bash
npm install -g pnpm
```

Then, install the dependencies:

```bash
pnpm install
```
